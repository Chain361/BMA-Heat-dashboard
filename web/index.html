คุณภาพข้อมูลและข้อจำกัด

    • Landsat ถ่ายภาพราว 10:30 น. จึงไม่มีข้อมูลตอนบ่ายและกลางคืน
    • LST คืออุณหภูมิพื้นผิว ไม่ใช่อุณหภูมิอากาศที่คนรู้สึก
    • เกณฑ์ภาพปลอดเมฆ 80% และกริด 250 ม. เป็นค่าที่ตั้งขึ้นเอง
    • ความสัมพันธ์ไม่ได้แปลว่าเป็นเหตุและผล (วิเคราะห์แบบภาคตัดขวาง)
